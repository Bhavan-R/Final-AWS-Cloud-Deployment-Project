# Demo video guide (record your real project)

Suggested duration: 2–3 minutes. Record your screen with your actual application and AWS console. This file is a script/outline only; it is not a recorded video.

1. **Introduction (10–15 sec):** State project name: CloudTask – AWS Final Cloud Deployment Project.
2. **Application demo (40–60 sec):** Open the website, add a task, change priority, mark it completed, filter the list, and delete a task.
3. **AWS deployment (40–60 sec):** Show EC2 instance details (hide sensitive account information), security group inbound rules with SSH restricted to your IP, and the website open from the public EC2 IP.
4. **AWS services (20–30 sec):** Show your actual S3 bucket and CloudWatch metrics if configured.
5. **Architecture (15 sec):** Briefly explain the architecture diagram.
6. **Closing (10 sec):** Summarize what you learned.

Before sharing, avoid showing account IDs, email addresses, access keys, private keys, billing details, or personal information.
